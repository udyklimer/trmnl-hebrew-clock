Install Hebrew Clock

Put the clock firmware on a new device from this page. Nothing needs to be installed on this computer.

  1. Connect the device to this computer with a USB-C cable.
  2. Click Install below and choose the device's port from the list.
  3. When asked, choose to erase the device. Installing takes about a minute.
  4. When it is done, the clock shows Set up your clock. Follow the steps on its screen.
This browser can't install firmware. Please open this page in Chrome or Edge on a computer. Installing needs a secure (https) connection to this page.

The device doesn't show up in the list? Unplug it, hold the small B button on the little board while plugging it back in, then click Install again.
After this first install, the clock updates itself over Wi-Fi.
